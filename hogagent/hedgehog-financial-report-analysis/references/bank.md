# 银行分析策略（comp_type = 2）

银行是以资本约束经营信用风险和流动性的杠杆生意。普通工商业的毛利率、存货和经营现金流框架不适用，优先判断净息差、资产质量、负债质量、拨备和资本充足性。

## 1. 核心分析顺序

1. **盈利引擎**：净利息收入由生息资产规模与净息差驱动；非息收入看手续费、财富管理、投行及投资收益的稳定性。
2. **资产质量**：不良率只是结果，继续检查关注类、逾期、重组、阶段二贷款、迁徙率、核销、信用成本、拨备覆盖率和行业/区域/客户集中度。
3. **负债质量**：存款增长、活期占比、付息率、同业与市场化融资依赖、存贷比和流动性覆盖；规模增长不能以高成本负债掩盖。
4. **资本约束**：核心一级资本、资本充足率、风险加权资产增速和内生资本补充。利润增长但资本消耗更快，不等于财务质量改善。
5. **资本收益质量**：ROE 要拆为息差、杠杆、信用成本和费用效率，检查高 ROE 是否依赖低拨备或高杠杆。

## 2. 利润质量与多空证据

- 多头证据：净息差企稳、核心存款增长、手续费恢复、信用成本下降且前瞻指标同步改善、资本内生增长。
- 空头证据：以债券投资收益/公允价值变动支撑利润，拨备释放快于风险改善，关注/逾期/阶段二先上升，不良生成和核销压力增加，存款成本上升。
- `经营现金流/净利润` 对银行不具普通工商业含义，不以此判利润质量；用利息收入现金实现、资产质量迁徙和拨备变动替代。

## 3. 附注重点

- 贷款五级分类、逾期与不良交叉表、重组贷款、阶段一/二/三余额及 ECL 参数；
- 房地产、地方融资平台、小微、信用卡和单一大客户敞口；
- 投资资产分类、公允价值层级、减值、非标和同业敞口；
- 存款期限结构、付息率、同业负债和流动性指标；
- 核心一级资本、资本工具、风险加权资产、监管处罚、表外理财与担保承诺。

## 4. 成本与研发

- 用成本收入比、业务及管理费、员工成本、网点/渠道投入评价效率；费用下降需排除投入不足或一次性节省。
- 金融科技和研发投入优先取年报附注/管理层讨论中的同口径披露，分析投入强度、人员和业务转化。未披露时标注缺失，不能用现金流“支付职工现金”替代研发费用。

## 5. 优先字段与报告指标

- API：`int_income, int_exp, n_commis_income, invest_income, fv_value_chg_gain, credit_impa_loss, decr_in_disbur, depos, depos_ib_deposits, total_assets, total_liab, netprofit_margin, roe_waa`
- 公告/附注：净息差、不良率、关注率、逾期率、拨备覆盖率、信用成本、存款付息率、成本收入比、核心一级资本充足率、流动性覆盖率。

监管指标以公司报告口径和当期监管规则为准，不能用通用经验阈值代替公司事实。
