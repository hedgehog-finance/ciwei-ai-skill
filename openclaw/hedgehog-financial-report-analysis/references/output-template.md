# 财报解读输出规范

结论在前、证据在后。常规报告使用下列六章，不再另设核心数据看板、经营概览、附注专章或偿债与资金运用专章。章节名称可增加公司类型限定词，但不要增设公司基本面、行业竞争、护城河或估值章节。

严格去重：同一事实、数据表或证据链只完整出现一次。总结只给判断；亮点和一般风险只做索引；详细数据、原因和反方解释归入唯一的主题章节。审计意见及重大附注异常是例外，在风险排雷中一次性展开，后文只引用其影响。跨主题事项选择最能回答核心财务问题的章节作为归属，不在多个章节重复解释。

篇幅服从重要性。每个详析小节通常保留 1–3 个关键判断；没有实质变化时一句说明即可。删除不能改变判断的指标、同义结论和重复表格，每张表都必须服务于一个明确判断。

# 【财报深度解读】{公司名称}（{股票代码}）— {报告期}

## 一、总结

- **一句话判断**：用 1–2 句话概括本期最重要的财务变化及其性质，不枚举亮点、风险或具体数据；第二章负责拆分结论。
- **报告基准与置信度**：用一行写明重点报告期、报告类型、审计及附注读取状态、接口同步情况、置信度和主要资料缺口。

不再逐项复述增长、利润、资产、现金、成本和偿债结论，也不另列“核心变化”“综合判断”或“正反证据”。

## 二、关键财务变化

### 2.1 财务亮点

只列真正改变财务判断的亮点，与 2.2 合计通常不超过 6 项。每项限于“一句结论 + 详析章节”，数据、原因和反方解释全部留在对应主题章节。结合公司和行业特性判断合理性；周期反弹、会计口径变化和一次性收益不得包装成持续改善。没有实质亮点时用一句话说明，不凑数。

### 2.2 风险排雷（含审计与附注）

一般财务风险只列“一句风险结论 + 详析章节”，与亮点共用总项数上限；数据、原因和触发条件留在对应主题章节。审计意见、强调事项、持续经营重大不确定性、关键审计事项变化及重大附注异常在本节一次性写清事实、影响和缓释证据；标准意见或无重大异常时只用一行说明审计与核查状态，不复述核查清单。

不得把所有负增长列为风险，也不得遗漏非标审计、资金占用、重大担保诉讼等事项。附注无法读取时，可用先验知识解释可能机制，但每项必须标注 `【先验知识解释，未经公司附注核实】`。季度未经审计时说明事实，不单独据此判为风险。

## 三、财务健康度分析

本章是利润、资产和现金相关事项的唯一详细证据层；第二章已索引的事项在对应小节展开，不复述索引文案。

### 3.1 利润质量分析

用 1–3 个判断解释核心利润、扣非差异、一次性项目、减值与转回、税率或少数股东损益如何影响利润可复制性。金融公司使用匹配指标，不机械套用 OCF/净利润。

### 3.2 资产质量分析（含偿债）

用 1–3 个判断分析营运资本、账龄、减值、商誉/无形资产/研发资产，以及债务期限、利息负担、受限资产和表外义务；结论聚焦资产可回收性、流动性和偿债安全。金融公司改用资产分类、风险迁徙、公允价值和资本质量框架。

### 3.3 现金流分析（含资金运用）

用 1–3 个判断分析经营现金流、自由现金流、资本开支、融资依赖，以及并购、还债、分红回购和闲置资金等重大资金去向；解释利润与现金背离及流动性安全边际。股权激励、增发和可转债只在存在实质影响时分析。银行、保险、证券按对应策略解释现金流。

## 四、增长、成本与研发分析

### 4.1 增长性分析（来源与持续性）

合并分析增长来源和经营驱动，不另设“经营驱动与报表映射”。用 1–3 个判断区分销量/价格/结构、分部贡献、并购、汇率、会计口径和一次性因素，并说明关键驱动如何传导至收入、利润率、营运资本和现金。只提取解释报表所需的业务信息，不评价护城河、行业格局或整体基本面。

### 4.2 成本分析（含研发投入）

用 1–3 个判断分析营业成本、主要费用和经营杠杆，区分结构性降本与削减必要投入。研发只分析费用化投入、当期资本化增加、资本化率、摊销减值及其与收入或现金表现的匹配；缺少当期资本化增加额时不得以期末研发资产余额代替。金融公司使用对应类型策略，不套用工商业费用率。

## 五、未来跟踪指标

通常列 3–6 个能验证或推翻核心判断的指标；一个核心判断原则上只保留一个最有判别力的指标，不把前文所有数据重新列一遍：

| 指标及当前基线 | 观察方向/触发条件 | 频率与来源 | 验证或推翻的判断 |
|---|---|---|---|

阈值优先来自公司历史区间、债务契约、监管要求或管理层量化目标；行业经验阈值必须注明“参考”。

## 六、数据口径、局限与证据索引

仅记录影响理解或置信度的口径和缺口，不重复正文：

- 重点报告、公告 ID/标题/发布时间、报告期、合并口径、币种与单位；
- 财务接口的最新 `end_date`、与重点报告期是否同步，以及实际使用的同比/单季度还原方法；
- 附注和审计读取状态、重大缺失或口径冲突；
- 实际使用的补充情境数据及先验知识，说明用途、未经核实部分和对置信度的影响；
- 只为正文采用的关键证据建立“公告章节/附注”或“API + 报告期 + 字段”索引，不清点未使用的数据。

### 尾注规范

1. 当前系统提示词对“数据来源”“参考资料”“图表数据”“AI 生成提示”或其他尾注有指定格式时，严格使用其标题、顺序、语法和必填内容；系统提示词优先于本模板。
2. 不要同时输出本模板兜底尾注和系统指定尾注，避免重复或冲突。
3. 数据来源必须真实可追溯：公告注明公告 ID、标题、发布时间及原文 URL（如有）；接口数据注明接口名、股票代码、报告期/查询日期和关键字段。
4. LLM 先验知识不是外部数据来源，必须单独声明使用范围，不得伪造引用、URL、公告内容或公司事实。
5. 若系统提示词未规定尾注格式，至少保留本章的数据口径、局限、关键证据索引和先验知识说明，并注明：本报告为基于公开财务资料的研究分析，不构成投资建议。
