# 证券公司分析策略（comp_type = 4）

证券公司的财务表现受资本市场活跃度驱动，利润波动取决于业务结构、资本使用效率和风险控制。区分经纪、投行、资管、信用和自营，不把牛市公允价值收益当作可持续盈利能力。

## 1. 核心分析顺序

1. **收入结构**：经纪看成交与佣金率，投行看项目储备与发行节奏，资管看主动管理和费率，信用业务看两融/股票质押规模与利差，自营看方向性和非方向性收益。
2. **盈利质量**：手续费类经常收入、利息净收入与投资/公允价值收益分开；利润增长若主要来自市场 beta，给予较低可持续性。
3. **杠杆和流动性**：剔除代理买卖证券款后的真实杠杆、短期融资、债券、流动性覆盖和净稳定资金率。
4. **风险资产**：交易性金融资产、衍生品、融出资金、股票质押、信用减值和 Level 3 公允价值资产。
5. **资本效率**：净资本、风险覆盖率、ROE、各业务资本占用和股权融资摊薄。

## 2. 利润质量与多空证据

- 多头证据：手续费和资管等经常收入占比提高、市场份额和费率稳定、ROE 改善不依赖加杠杆、自营风险调整后回报稳定、净资本充足。
- 空头证据：公允价值变动或处置收益主导增长、经纪佣金率持续下滑、投行项目中断、两融/质押减值上升、短债扩张支持方向性自营。
- 经营现金流受客户资金和金融资产交易影响，波动大；必须结合代理买卖证券款和处置交易性金融资产净额解释，不能套用普通工商业 OCF/净利润标准。

## 3. 附注重点

- 金融资产分类、公允价值层级、Level 3 估值参数和敏感性；
- 衍生品、回购、融资融券、股票质押、集中度和信用减值；
- 代理买卖证券款与客户资金隔离，受限资产和流动性指标；
- 投行承销诉讼/处罚、资管产品风险承担、关联交易；
- 净资本、风险覆盖率、资本杠杆率、流动性覆盖率和净稳定资金率。

## 4. 成本与研发

- 分析业务及管理费、员工薪酬、成本收入比和薪酬递延/追索机制。收入下降时成本刚性决定利润弹性。
- 信息技术和研发投入从报告取同口径数据，评价交易、风控、机构服务和财富管理转化。不能把 IT 资本开支全部等同研发。

## 5. 优先字段与报告指标

- API：`n_sec_tb_income, n_sec_uw_income, n_commis_income, invest_income, fv_value_chg_gain, credit_impa_loss, lending_funds, trad_asset, acting_trading_sec, st_fin_payable, n_incr_disp_tfa, n_cash_flows_fnc_act, roe_waa`
- 公告/附注：经纪市占率与佣金率、投行项目、资管 AUM 与主动管理占比、两融/质押风险、净资本及四项核心风控指标。

所有资本和监管指标以报告期有效规则为准；市场上涨带来的单期自营收益不能外推为长期复合增长。
