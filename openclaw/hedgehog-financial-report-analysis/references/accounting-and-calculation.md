# 会计口径、附注与证据规则

每次财报解读都使用本参考。它规定报告期选择、季度还原、附注核查、审计判断和通用财务质量方法。

## 1. 报告期与比较口径

### 最新报告选择

“最近公告”不一定等于“最新报告期”。先按报告期排序，再处理同一报告期的版本：

1. 完整修订/更正稿；
2. 完整原报告；
3. 摘要、英文版、提示性公告只作线索，不作正文替代。

主分析期默认取最新完整官方定期报告的报告期，而不是各接口最晚共同交集。三表、财务指标接口用于核对和补充历史：

- 接口与公告同步：交叉核验后使用；
- 接口滞后：从公告原文取最新三表，接口只补历史，不下调主分析期；
- 接口领先：重新检索对应报告期的 U1 公告；没有完整官方报告就不把接口期作为主分析期；
- 最新公告正文和三表均无法可靠取得：才退回资料完整的最近报告期，并明确局限。

财务指标接口缺失不妨碍报告期成立，可按同口径三表计算或留白。接口 `ann_date` 必须符合用户的分析截止日。

### 流量、存量与比率

- 利润表和现金流量表通常为年初至报告期末累计数。
- 资产负债表是期末时点数，直接比较季末，不做差额还原。
- 财务比率不能直接相减还原单季度；需要时用单季度分子和匹配的平均资产/权益重新计算。
- 同比优先比较相同累计区间；边际趋势使用可验证的单季度流量。

单季度还原只适用于同口径流量科目：

| 单季度 | 计算 |
|---|---|
| Q1 | 一季报累计数 |
| Q2 | 半年报累计数 − 一季报累计数 |
| Q3 | 三季报累计数 − 半年报累计数 |
| Q4 | 年报累计数 − 三季报累计数 |

还原前确认合并范围、会计政策、追溯调整和单位一致。任何一项不一致就不计算，改用同口径累计同比。

## 2. 附注必查清单

先在完整公告中定位下列章节，再按异常方向扩展阅读：

1. 审计报告、审计意见基础、强调事项、持续经营重大不确定性、关键审计事项；
2. 重要会计政策和会计估计、政策/估计变更、前期差错更正；
3. 营业收入及分部信息：确认时点、履约义务、退货/可变对价、客户与供应商集中度；
4. 应收款、合同资产、存货、长期资产、商誉和金融资产的账龄、减值方法与转回；
5. 研发支出的费用化与资本化条件、当期增加、摊销、减值；
6. 货币资金和其他资产的受限情况，借款期限、利率、抵押质押和契约条款；
7. 关联方、关联交易、资金占用、担保、承诺、或有事项、诉讼与监管处罚；
8. 政府补助、投资收益、公允价值变动、资产处置、营业外项目和非经常性损益；
9. 所得税、递延所得税资产的可实现性、税率异常；
10. 租赁、并购、商誉形成、少数股东权益、股权激励；
11. 资产负债表日后事项、利润分配、再融资和重大投资；
12. 母公司与合并报表差异、子公司受限资金和利润上划能力。

不要只引用会计政策模板。真正有信息量的是本期变化、金额、假设、账龄、敏感性、到期结构及管理层估计。

## 3. 审计意见判断

| 情形 | 判断原则 |
|---|---|
| 标准无保留意见 | 只说明报表在重大方面公允反映，不代表无经营风险或无舞弊 |
| 带强调事项/持续经营重大不确定性段的无保留意见 | 意见仍为无保留，但相关事项必须进入高优先级风险 |
| 保留意见 | 识别涉及科目、影响范围、是否可量化及连续性；通常显著降低可信度 |
| 否定意见 | 报表整体存在重大且广泛错报，财务结论可信度极低 |
| 无法表示意见 | 审计范围或证据严重受限，不能把账面利润和资产作为可靠基础 |

关键审计事项是审计资源投入的重点，不自动等于错报。结合 `queryFinanceAudit` 与公告审计报告交叉核对审计机构、签字会计师、费用和意见；关注连续更换、辞任、费用异常、同一事项连续多年出现。

## 4. 通用分析方法

本节的具体科目和比率默认适用于一般工商业。银行、保险、证券遇到不适用或冲突时，以对应公司类型策略为准；仍保留“区分核心与一次性、核对资产可回收性、解释资本约束、寻找反证”的通用原则。

### 利润质量

- 核心经营利润：剥离政府补助、投资/公允价值变动、资产处置、营业外项目等非核心来源后看趋势。没有完整口径时不要伪造“调整后利润”。
- 扣非净利润与归母净利润的差异：判断非经常项目是否决定增长。
- 现金含量：`经营现金流 / 净利润` 观察同口径累计期和 3–5 年完整年度；净利润为负或接近零时不用该比率，直接分析现金缺口。
- 应计压力：可用 `(净利润 − 经营现金流) / 平均总资产` 辅助判断，必须保持同口径并解释营运资本和非现金项目。
- 税率、少数股东损益、减值转回和一次性收益均需检查。

### 资产质量

- 收入增长与应收款、合同资产、存货增长对照；后者显著更快时检查账龄、周转和减值。
- 检查商誉、无形资产、资本化开发支出、递延所得税资产的可回收依据。
- 货币资金与有息负债并存时检查受限资金、币种、地域、子公司隔离和资金成本，不能简单净额化。
- 关注表外担保、回购承诺、保理追索权、供应链融资、诉讼和债务契约。

### 现金创造、偿债与资金运用

- 自由现金流通常用 `经营现金流 − 购建长期资产现金支出`；若直接使用接口 `free_cashflow/fcff`，先核对定义。
- 区分维持性与扩张性资本开支。负自由现金流可能来自扩张，也可能来自低效投资；结合 ROIC、产能利用率、后续收入和债务变化判断。
- 画清现金去向：再投资、并购、还债、分红回购或闲置。比较新增投入与新增经营利润/现金流。
- 检查经营现金缺口是否由借款、股权融资或处置资产持续填补。

### 成本与研发

- 比较营业成本、销售/管理/财务费用、研发费用与收入的增速和费用率，识别经营杠杆、降价压力或获客效率变化。
- 研发费用率：`当期费用化研发 / 同期营业收入`。
- 总研发投入强度应使用附注披露的当期费用化研发与当期资本化增加额。资产负债表 `r_and_d` 是期末余额，不能直接当作当期资本化投入。
- 研发资本化率只有在取得当期资本化增加额时计算：`当期资本化研发增加 / (费用化研发 + 当期资本化研发增加)`。缺少该数据就标注不可计算。
- 研发增加不是天然利好。结合产品收入、毛利率、专利/管线里程碑、人员和人均产出评估转化效率，并检查资本化、摊销和减值是否延后确认成本。

### 增长与可持续性

- 至少拆分收入、毛利、归母净利润、扣非净利润、经营现金流的增长是否同向。
- 识别增长来源：销量、价格、产品/客户结构、并购、汇率、会计口径、政府补助或资产处置。
- 用主营分部验证增长是否由高质量核心业务贡献，还是低毛利业务扩张制造规模。
- 财务上的可持续增长需同时通过利润率、营运资本占用、现金转化、资本开支回报和融资约束五项检验。
- CAGR 只用于起止值同号且口径一致的完整年度；否则使用绝对变化和分段趋势。

## 5. 异常值合理性解释与先验知识

财务值或指标显著偏高、偏低、突变、转正、转负或与其他报表矛盾时，无论表面上是正面还是负面，均按以下顺序处理：

1. **核对口径**：单位、报告期、累计/单季度、合并范围、重述、会计政策、分母接近零和接口版本；
2. **建立公司情境**：用 `getStockBasic.industry` 核实行业，用 `queryStockCompany` 核实主营业务、业务范围、员工、注册资本和公司简介；需要规模、股本、稀释或市场背景时，再用 `queryDailyBasic` 取报告期附近或当前的 `total_share, total_mv, circ_mv` 等字段；
3. **匹配财务模式**：结合公司类型、行业周期、轻重资产、周转方式、收入确认和资本需求，列出该数值可能合理或异常的机制；
4. **寻找公司证据**：优先用公告正文、附注、三表勾稽、主营构成及历史序列验证；
5. **双向检验**：同时写出最强的正面解释和负面解释，说明哪项证据能确认或推翻；
6. **条件定性**：按“合理 / 需观察 / 存疑 / 高风险 / 证据不足”等有条件结论表达，并给出置信度和跟踪指标。

不得把行业参考区间当成公司结论，也不得用股价、PE/PB 或市值直接证明财务质量。`queryDailyBasic` 的估值和市场字段只能作为背景，除非用户另行要求估值分析。

### 附注不可得时

- 可以使用 LLM 先验知识解释常见行业惯例、商业模式和会计机制，但输出中逐项标注 `【先验知识解释，未经公司附注核实】`。
- 先验知识只能生成“可能原因”和核查方向，不能确认公司的收入政策、减值假设、关联交易、受限资金、担保诉讼、债务契约或审计结论。
- 不得伪造公司事实、附注内容、同行数据或来源；无法验证就保留多个解释并写“证据不足”。
- 总结和数据局限中必须说明附注缺失范围、先验知识使用范围及其对置信度的影响。

## 6. 证据、反证与置信度

每个重大结论至少记录：

- 来源：公告 ID、标题、章节/附注名称，或 API、`end_date`、字段；
- 事实及单位；
- 同比、上季末或历史基准；
- 正面解释与负面解释；
- 是否使用先验知识及其未核实边界；
- 当前判断及其失效条件。

置信度按证据完整性给出高/中/低：公告原文和附注完整、三表与可用指标同口径且可勾稽时才可为高。附注缺失、接口与报告期不一致且无法解释、重大科目不可解释或非标审计意见都会降低置信度。
