# 保险公司分析策略（comp_type = 3）

保险是“先收保费、后履约赔付”，财务结果由负债端承保质量、费用/退保差异与资产端投资回报的长期匹配共同决定。先确认报告采用的保险合同会计准则和新旧口径，不跨口径直接比较。

## 1. 核心分析顺序

1. **业务质量**：寿险关注新业务价值、价值率、期缴/续期、退保和代理人产能；财险关注保费结构、赔付率、费用率和综合成本率。
2. **合同负债与利润释放**：采用新保险合同准则时，关注合同服务边际（CSM）、保险服务收入/结果、金融变动列报选择及假设变动；不要只看保费规模。
3. **投资与资产负债匹配**：总/净投资收益率、综合投资收益、资产配置、久期、信用风险、公允价值层级和利差损风险。
4. **资本与偿付能力**：核心/综合偿付能力、最低资本、资本补充工具和压力情景。
5. **现金与分红**：保费现金、赔付与退保、母公司可用现金、子公司利润上划和资本约束。

## 2. 利润质量与多空证据

- 多头证据：新业务价值与价值率增长、续期和期缴改善、CSM 稳定增长、财险综合成本率低于 100%、投资回报覆盖负债成本、偿付能力充足。
- 空头证据：短期趸交推动规模但价值率下降、退保上升、精算假设放宽释放利润、承保亏损依赖投资收益、权益行情或公允价值变动主导利润、偿付能力下滑。
- 保险现金流与利润受合同分类及投资交易影响，不机械使用普通工商业 OCF/净利润阈值。

## 3. 附注重点

- 折现率、死亡率/发病率、退保率、费用率等精算假设及敏感性；
- CSM、履约现金流、风险调整、亏损合同组的期初期末变动；
- 寿险新业务价值/内含价值方法与假设，财险综合成本率拆分；
- 投资资产类别、信用评级、减值、公允价值层级、非标资产与关联方敞口；
- 资产负债久期匹配、最低保证利率、再保险安排、巨灾风险；
- 偿付能力、资本补充、监管措施和分红限制。

## 4. 成本与研发

- 寿险拆获客佣金、保险服务费用、管理费用和续期维护；财险拆赔付率与费用率，判断降本是否以业务质量恶化为代价。
- 数字化/研发投入从报告披露取数，评价代理人效率、获客成本、核保理赔效率和客户留存的转化。未披露时明确留白。

## 5. 优先字段与报告指标

- API：`prem_earned, prem_income, prem_refund, compens_payout, invest_income, fv_value_chg_gain, rsrv_insur_cont, prem_fr_orig_contr, n_cashflow_act, roe_waa`
- 公告/附注：新业务价值及价值率、CSM、内含价值、期缴/续期占比、退保率、综合成本率、总/净投资收益率、核心/综合偿付能力充足率。

会计口径变化或公司自定义指标必须说明定义，不能把不同公司的“综合投资收益率”等名称相近指标直接横比。
